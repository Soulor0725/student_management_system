# Prometheus 配置说明

## 一、监控指标已添加

项目已在以下接口添加 Prometheus 监控指标：

1. 注册接口 (/register)
2. 登录接口 (/login) 
3. 新增学生接口 (/students)

## 二、Prometheus 配置

在你的 prometheus.yml 文件中添加以下配置：

```yaml
scrape_configs:
  - job_name: 'student-management'
    scrape_interval: 5s
    static_configs:
      - targets: ['localhost:5000']
    metrics_path: '/metrics'
```

## 三、监控指标列表

| 指标名称                      | 类型     | 说明                                      |
|-------------------------------|----------|-------------------------------------------|
| register_requests_total       | Counter  | 注册请求总数（status: success/fail）      |
| login_requests_total          | Counter  | 登录请求总数                              |
| add_student_requests_total    | Counter  | 新增学生请求总数                          |
| http_requests_total           | Counter  | HTTP 请求总数（所有接口）                 |
| http_request_duration_seconds | Histogram | HTTP 请求响应时间分布                     |
| in_flight_requests            | Gauge    | 正在处理的请求数                          |

## 四、启动应用

```bash
cd student_management
python app.py
```

然后访问 http://localhost:5000/metrics 查看指标
